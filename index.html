SkillSmith
Agent Skills open standard · Google Gemma 4

Give any AI agent a new skill in 30 seconds.

Agent Skills are folders with a SKILL.md that teach coding agents a task. SkillSmith forges a spec-compliant skill from a one-line idea with open-weight Gemma 4, checks it against the agentskills.io rules and auto-repairs it. It also validates any SKILL.md you paste. The same tools ship as a CLI and as a skill of their own.
